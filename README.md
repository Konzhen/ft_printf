# ft_printf

Réimplémentation en C d’une partie de printf pour le tronc commun de 42. Le projet analyse une chaîne de format et écrit le résultat sur la sortie standard.

## Conversions

La version fournie prend en charge les caractères, chaînes, pointeurs, entiers signés et non signés en décimal, hexadécimal minuscule et majuscule, ainsi que le caractère `%`.

## Compilation et utilisation

Lancer `make`, inclure `ft_printf.h`, puis lier la bibliothèque statique générée au programme C. Les règles `clean`, `fclean` et `re` nettoient ou reconstruisent le projet.

Le sujet officiel est consultable sur la [page Projets de l’intranet 42](https://projects.intra.42.fr/) après connexion. Le PDF n’est pas recopié dans ce dépôt.
